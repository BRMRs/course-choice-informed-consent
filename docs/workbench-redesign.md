# 选课工作台重做基线

本文件按最新用户反馈覆盖 PRD v1 中的宣传式首页、固定闯关路径、四张课程卡片和站内设计讲解。目标是可实际办理的选课工作台。

## 产品约束

- 首屏就是选课工作台：轮次、学生培养信息、筛选器、单列课程表和待提交课程。无宣传大标题、装饰插画、英文眉题或体验任务卡。
- 桌面用紧凑单列表格，字段包含课程/教学班、学分、教师、时间地点、容量、适配与选课操作；手机保留同一顺序的行式列表。
- 12 门完整课程数据，支持课程名/课程号/教师搜索、学院/类别/余位过滤与排序。每一门都能查看完整详情、选入和退选；满员、冲突和学分限制有确定反馈。
- 区分待提交方案、已提交结果、每周课表。最低3学分，最多12学分；可以自由选择其他课程，也可以仅提交机器学习。
- 课程、课表、结果使用真实 hash 导航，支持浏览器返回及直接打开。重要状态本地保存；刷新恢复办理中的手续。学校、学生和数据虚构，说明集中于“关于系统”，不打断业务。
- 配色重做：浅灰工作区、白色表格、石墨色正文、清晰蓝色操作；琥珀色只承担待处理/建议，绿色只承担成功/已选。强化行对齐和业务信息密度。

## 故意的制度阻碍

1. 综合适配默认排序：机器学习搜索中优先插入三门机构推荐课程，正常列表呈现；可以切换排序，不在产品内揭露“个人兴趣只占10%”。
2. 用户点击机器学习的正常“选课”操作时触发重点推荐课程知情确认，课程说明、拒绝理由、理解题、最终确认在同一业务对话框里办理。关闭后能继续上次进度。
3. 完成手续并选入机器学习时一次性加入农业课保障席位。用“保障席位”来源和简短操作通知明确新增，保留原拒绝记录；退选时触发声明和连续两秒确认。移除后不回填。
4. 用户核对提交时显示培养建议78分及补充建议，但真实学分要求已满足时始终能提交。无假失败、没有提交后改课。

## 验收门槛

- 线上页面无“本次任务”“交互演示”“你已具备拒绝条件”“设计解析”“选择权账单”等讲解层文案；关于系统中允许简短说明虚构数据。
- 首屏可看见筛选器、表头与多行课程；无2×2或其他课程卡片宫格。
- 搜索其他课程/教师、组合过滤、详情、普通选退课、冲突/满员、课表和结果均可实际操作。
- 机器学习完整路径实际经过至少三类阻碍，最终可以只提交机器学习。错误答案可重试，已拒绝手续保存，保障课不回填，提交结果与核对一致。
- 提交后仍可查看课程和课表；通过明确“调整选课”创建新草稿，再提交生成新版本，旧回执不被修改。
- 独立代理审查、测试与浏览器验收后，通过PR合并并发布；最终公开地址和源代码链接匿名测试。
