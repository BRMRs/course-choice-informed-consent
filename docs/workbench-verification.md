## 实际浏览器操作

- 首页为单列表格和待提交方案，12 个教学班，无宣传首页和任务卡。
- 搜索教师“沈亦宁”得到信息可视化课程，并正常选入。
- 搜索机器学习得到三门推荐与目标课；已选可视化课程时，机器学习的时间冲突被明确拦截。
- 普通退选后点击机器学习“选课”触发手续；完成阅读后关闭、再次打开，进度保留。
- 错误答案后刷新，原拒绝理由和当前核验步骤保留；重新作答可继续。
- 完成确认自动选入机器学习和农业保障课；每周课表对应显示两门课的周次、时段与教室。
- 浏览器返回保留搜索条件；保障课撤销400ms短按无效，键盘空格持续两秒可成功。
- 以78分培养建议提交仅机器学习的3学分方案，刷新后结果编号和课程保持一致。
- 点击“调整选课”，加入教育统计，提交第二版5学分方案；历史中第一版仅机器学习、3学分和原提交时间保留。
- 再次退选并选入机器学习，不重复知情手续，也不回填农业保障课。
- 390px模拟宽度无横向溢出，课程保持逐行显示；底部固定栏可以查看方案及核对提交。
- 两个同源标签分别选入专家系统与城市生态，两次修改均保留，合计9学分；一页输入“机器人”尚未查询时，另一页退课后输入内容仍保留。

## 独立审查与修复

两名子代理分别负责课程模块/业务测试与独立实现审查。审查发现的跨标签同时写入、旧核对框提交、表单输入清空、模态框焦点、跳过导航路由、手机系统信息名称问题均已修复并复核。

跨标签写入在 Web Locks 独占事务内读取最新数据再转换与保存；不支持该能力时使用独立标签页存储。提交必须携带用户当前页面实际核对的课程快照，过期时在核对框内显示重新核对提示。
